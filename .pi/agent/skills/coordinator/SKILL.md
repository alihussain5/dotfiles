# Workmux is disabled

Do not invoke `workmux` for any reason.

Do not spawn, monitor, communicate with, or merge worktree agents.

For coding tasks, work directly in the current checkout using the normal file-reading, editing, and command-execution tools.

If a task is large, handle it incrementally in the current session rather than delegating it.
